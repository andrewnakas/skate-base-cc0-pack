# skate-base-cc0-pack

These are the files of the **skate-base-cc0** pack: original, public-domain ([CC0 1.0](LICENSE)) base assets for
community skate maps. They are served straight from GitHub Pages, so tools can fetch only the assets a map
uses:

```
https://andrewnakas.github.io/skate-base-cc0-pack/index.json
https://andrewnakas.github.io/skate-base-cc0-pack/meshes/<id>.glb
https://andrewnakas.github.io/skate-base-cc0-pack/textures/<name>.png
```

The generator, the design notes and a one-file zip download live in
[skate-base-cc0](https://github.com/andrewnakas/skate-base-cc0).

## Format

- **`index.json`** has these keys:
  - `assets`: maps an id to its `{ class, file, alias? }`;
  - `aliases`: maps a second id to the asset id it stands for;
  - `textures`: maps a texture id to its `{ role, file }`.
- **`meshes/<id>.glb`** holds two nodes:
  - a `visual` node, using KHR_mesh_quantization (16-bit positions under the node's scale) and
    KHR_texture_transform (16-bit UVs);
  - a full-precision `collision` node, which lists its surfaces in `extras.surfaces`.

  The grind lines are in `scenes[0].extras.grind`. Everything is in metres, Y is up, and each asset uses its own
  local frame.
- **`textures/`** holds tileable procedural surfaces (colour, normal, mask and opacity) for concrete, asphalt,
  metal, wood, grass, rock, brick, foliage, paint and glass.

Every mesh passes the Khronos glTF validator. Everything here was generated by code; see the generator repo for how.
